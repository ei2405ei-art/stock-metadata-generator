Stock Image Generator

Генерация изображений для Adobe Stock · этап 1: промпт, форматы, вариации · SiliconFlow (качество), fal.ai и Pollinations (бесплатно)

Промпт

Формат:
1920 × 1080 px
Вариаций за раз:
Укажите промпт и нажмите «Сгенерировать». Ctrl+Enter в поле промпта — тоже запуск. Из серии работ на Adobe Stock отправляйте 1 лучший кадр, иначе отказ «похожий контент».

Формат задаётся размером холста. Для Adobe Stock фото нужно ≥ 4 Мп (например 2400×1800) — бесплатный Pollinations даёт до ~1920 px по стороне, для большего подключите fal.ai или апскейл (следующие этапы).

Источник генерации

Pollinations бесплатно без ключа
Модель flux, работает сразу. Анонимный лимит: примерно 1 запрос в 10–15 секунд — при ответе 402 приложение само подождёт и повторит. Размеры до ~1920 px по стороне.
SiliconFlow качество регистрация без карты
FLUX.1-dev, FLUX.2, Qwen-Image — качественная генерация, размеры до ~2.4 Мп, negative prompt (Qwen-Image, FLUX-1.1-pro). Регистрация: cloud.siliconflow.com (email или Google), ключ: Account → API Key. Часть моделей бесплатна, остальные списывают баланс (~$0.01–0.05 за картинку).

Ключ хранится только в этом браузере. Откройте cloud.siliconflow.com → Account → API Key и скопируйте. Баланс и цены моделей — там же в Playground/ Billing.

fal.ai платно ключ
Качественные модели (FLUX dev/schnell, Recraft и др.), крупные размеры, ~$0.003–0.03 за изображение. Ключ: fal.ai → Dashboard → API Keys.

Ключ хранится только в этом браузере (localStorage). Проверится первой генерацией: 401 — ключ неверный, 402 — нет кредитов.

Настройки сохраняются автоматически. OpenRouter, OpenAI и Gemini с вашей сети недоступны (403), Hugging Face бесплатным аккаунтам не даёт кредитов (нужна карта) — рабочий путь: SiliconFlow.
