Анализ коммерческого потенциала (§4 скилла)

Четыре направления: сезонные темы · evergreen · недооценённые подтемы · переходные. Для каждой темы: покупатели, коммерческая задача, причина актуальности, возможности уникальных кадров, риски, приоритет. Бейдж факт = подтверждённый источник (helpx.adobe.com / Adobe Trends, проверено окт 2026); гипотеза = оценка, не доказанный факт продаж.

Спрос подтверждается только вашей статистикой — считайте оценки гипотезами, пока нет данных продаж. Микс портфеля по рекомендации Adobe: 50% evergreen · 30% сезон · 20% тренды.

Разработка серии (§5 скилла)

Одна серия — одна коммерческая тема, но разные визуальные задачи. Каждый кадр отличается минимум по двум значимым параметрам: сюжет, композиция, ракурс, метафора, задача покупателя. Матрица строится по структуре: кадры 1–3 — детали и текстуры, 4–6 — широкие сцены с copy space, 7–9 — действия и ситуации, 10–12 — необычные ракурсы и метафоры.

Промпты серии (§6–7 скилла)

Каждый промпт самостоятельный (никаких «как в прошлом кадре»): EN, --ar в конце, negative общий + кадровый, имя файла ≤30 символов. Совместимость слотов проверяется: aerial не мешается с indoor, тёплый свет только с тёплым настроением.
