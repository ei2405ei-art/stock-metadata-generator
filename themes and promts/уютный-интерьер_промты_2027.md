**Тема:** камин, тёплый свет, плед — **без рождественского клише**, вечная «зима».
**Форматы:** фото JPEG (p01–p10) + видео MP4 (vid01–vid10).
**Дедлайн:** зимний пик — до **22 октября 2026**; evergreen-варианты (кофе/книга/камин без сезона) продаются круглый год.

## Правила перед генерацией

- **Без рождественского клише:** никаких ёлок, гирлянд, олених рогов и «Merry Christmas» — только тёплая зима.
  Такой кадр продаётся с октября по март и не привязан к одному году (evergreen-правило).
- **Люди в кадре = model release.** Поэтому в сетке преимущественно пустые интерьеры, руки без лица, спина,
  животные. Если генерируете людей — чекбокс «People and Property are fictional» (ИИ) + релиз (реальная съёмка).
- Видео: 5–60 с (вертикали 10–30 с), движение читается с первого взгляда, луп предпочтителен.

## Общий negative prompt

`text, watermark, logo, letters, signature, blurry, low quality, jpeg artifacts, extra limbs, deformed hands, cropped, christmas tree, ornaments, christmas decorations, garland, mockup, hdr, overprocessed`

## Что делать после генерации

**Фото (p01–p10):**
1. Апскейл до минимум 4 МП (лучше 12–24 МП) без «мыла».
2. Проверка в 100%: руки (p09), нет пересатурации/жёсткого HDR, естественные тона.
3. Экспорт: JPEG, sRGB, ≤45 МБ. Имя = из заголовка (≤30 символов).

**Видео (vid01–vid10):**
1. Нативное разрешение: горизонталь **1920×1080 / 3840×2160**, вертикали — **1080×1920 / 2160×3840 сразу**.
2. Длительность 5–60 с (вертикали 10–30 с), кадр 24/25/30.
3. Без текста, титров, переходов; движение обязательно — «мёртвые» кадры = отказ.
4. Кодек H.264 (MP4).

**Метаданные:**
- Title: 2 предложения, 120–180 символов, без дат.
- Ключи: 40–49, первые 3 — фразы; вертикали — обязательно `vertical` + `video`.
- `no people` + `nobody` — только для кадров без людей (p01–p08, p10, vid01–03, 05–10).
- ИИ: чекбокс «Created using generative AI tools».
