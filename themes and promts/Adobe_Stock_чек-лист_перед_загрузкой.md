# Чек-лист проверки файлов перед загрузкой на Adobe Stock
*Дополняет гайд `Adobe_Stock_ключевание_гайд.md`. Пройдите по пунктам перед каждым батчем — повторная модерация стоит лимитов загрузки (с мая 2025 действует лимит).*

---

## 1. Файл и имя файла
- [ ] Имя файла **до 30 символов**, включая расширение, латиницей, без пробелов (например, `waterfall-vertical-01.mov`).
- [ ] Файл переименован осмысленно (не `DSC_4567.jpg`) — имя участвует в загрузке и в CSV.

## 2. Фотографии — техника
- [ ] Разрешение **4–100 МП**; JPEG, профиль **sRGB**, размер файла **до 45 МБ**.
- [ ] Просмотрено в **100% масштабе**: резкость основного объекта, нет «мыла» и смаза.
- [ ] Экспозиция: нет выбитых светов / провалов в тенях (гистограмма).
- [ ] Баланс белого естественный, кожные тона живые (без «пластиковой» ретуши).
- [ ] Нет перезаострения, пересатурации, жёсткого HDR, артефактов обработки.
- [ ] Убраны пыль на матрице, хроматические аберрации (цветные каёмки по контрастным краям), мусор в кадре.
- [ ] Нет водяных знаков, таймкодов, рамок, брендинга.
- [ ] Горизонт выровнен; в композиции есть «воздух» под текст/дизайн.

## 3. Видео — техника
- [ ] Формат **MOV / MPG / MP4**, кодек **ProRes или H.264**.
- [ ] Длительность **5–60 сек** (вертикальным рекомендуется 10–30 сек), файл **до 3900 МБ**.
- [ ] Частота кадров из списка: 23.98 / 24 / 25 / 29.97 / 30 / 50 / 59.94 / 60.
- [ ] Разрешение — **нативное камеры**: горизонталь 1920×1080 / 2048×1080 / 3840×2160 / 4096×2160 / 4096×2304; вертикаль 1080×1920 / 2160×3840 / 2160×4096 / 2304×4096; квадрат 1080×1080 / 2160×2160.
- [ ] **Никакого апскейла** (HD→4K = отказ).
- [ ] Стабильность: штатив/стабилизатор; нет «желе», skеw, flash banding, мерцания.
- [ ] Экспозиция и цвет: log-материал приведён хотя бы к базовому Rec 709.
- [ ] В кадре нет логотипов, брендов, текста, титров, переходов, заставок.
- [ ] Движение в кадре есть (мёртвые стоп-кадры не принимаются), действие читается с первого просмотра.

## 4. Права и релизы
- [ ] Узнаваемые люди → **model release** заготовлен (одна форма на каждого человека, подписи читаемы, данные согласованы).
- [ ] Узнаваемая собственность / арт / современная архитектура как субъект → **property release**.
- [ ] Нет логотипов, товарных знаков, узнаваемой упаковки, чужих произведений (граффити, скульптуры, шрифты).
- [ ] Локация не в списке **known restrictions** (запрещённые объекты не принимаются даже с релизом).
- [ ] Файлы релизов — JPEG, имена совпадают с теми, что указаны в CSV (колонка Releases).

## 5. Заголовок (Title)
- [ ] До **70 символов** (для CSV — жёсткий лимит), без запятых и спецсимволов.
- [ ] Субъект + действие + окружение одним естественным предложением, без перечислений через запятую.
- [ ] Без брендов, имён людей, названий техники, терминов «made with …».
- [ ] Каждое важное слово из заголовка продублировано в ключевых словах.

## 6. Ключевые слова
- [ ] **До 49 ключей** (максимум 49; в CSV-спецификации указано «до 50» — не рискуйте верхней границей).
- [ ] **Первые 10 — самое важное**: главный субъект → действие → демография/количество → контекст.
- [ ] Порядок переставлен вручную (если ключи вшиты в Lightroom/Bridge — они в алфавитном порядке, обязательно переупорядочить в портале или в CSV).
- [ ] Существительные в единственном числе, глаголы в инфинитиве.
- [ ] Устойчивые фразы добавлены и фразой, и по отдельности (`arctic fox, arctic, fox`).
- [ ] Нет людей → есть `no people` и `nobody`. Есть люди → возраст, пол, этничность, эмоции, роли, количество (`one person`).
- [ ] Есть окружение (`indoors/outdoors, day/night`) и ракурс (`top view, high-angle view, close-up`).
- [ ] Концептов умеренно (2–5: `solitude, teamwork`), после фактических описаний.
- [ ] Тест на релевантность каждого ключа: «покупатель по этому запросу хочет увидеть этот файл?» Если нет — ключ удалён.
- [ ] Нет дублей ключей, брендов, имён, параметров камеры.
- [ ] Весь метаданные на **одном языке** (язык аккаунта).
- [ ] Видео: есть ключи `video`; вертикальное видео — обязательно `vertical` + `video` в заголовке или ключах.

## 7. Категория и CSV
- [ ] Категория соответствует содержанию (Sensei-подсказку проверил). Нумерация в CSV — по алфавитному списку: 1 Animals, 2 Buildings and architecture, 3 Business, 4 Drinks, 5 The environment, 6 States of mind, 7 Food, 8 Graphic resources, 9 Hobbies and leisure, 10 Industry, 11 Landscape, 12 Lifestyle, 13 People, 14 Plants and flowers, 15 Culture and religion, 16 Science, 17 Social issues, 18 Sports, 19 Technology, 20 Transport, 21 Travel *(сверьте с диалогом загрузки CSV в портале — номера показывает сам диалог)*.
- [ ] CSV: только `.csv`, кодировка **UTF-8** (в русском Excel — «CSV UTF-8»), **≤ 5000 строк**, **≤ 1 МБ**, имя файла без пробелов (`Ivanov_2026-10-05.csv`).
- [ ] Заголовочная строка точная: `Filename,Title,Keywords,Category,Releases` — не переименовывать и не переводить.
- [ ] Имена файлов в колонке Filename совпадают с загруженными байт-в-байт, включая расширение.
- [ ] Keywords взяты в кавычки, порядок через запятую = порядок важности; Title без запятых.
- [ ] Отправлять CSV **в той же сессии загрузки**, что и файлы, к которым он относится.

## 8. Генеративный ИИ (если применимо)
- [ ] Отмечен чекбокс **«Created using generative AI tools»** (всё, что создано/существенно изменено ИИ — включая генерацию новых субъектов и перекраску главного объекта; НЕ требуется для расширения фона, ретуши, удаления объектов).
- [ ] Люди/собственность выглядят реальными, но не основаны на конкретных людях → отмечен **«People and Property are fictional»**.
- [ ] Тип контента выбран честно: фотореализм → Photos, фэнтези → Illustrations, движущееся → Videos.
- [ ] Проверены: анатомия (руки, пальцы, лица), тени и отражения, текст «не поплыл», геометрия фона.
- [ ] В промптах, заголовке и ключах нет имён художников, реальных людей, персонажей, брендов, госорганов, «новостных» событий.

## 9. Отбор и портфель (стратегия)
- [ ] На один сюжет/ракурс/позу отобрано **3–5 лучших** кадров — остальные в архив (похожие серии = отказ «similar content»).
- [ ] Сезонный контент (Рождество, праздники) загружается за 2–3 месяца до сезона.
- [ ] Проверено: такой сюжет ещё не залит ранее в похожем виде (цветовые вариации, лёгкий кроп = похожесть).
- [ ] Для монтажа: ключи/метаданные у давно продающихся файлов не редактируются (риск сброса ранжирования).

## 10. Финальный проход (30 секунд перед отправкой)
- [ ] Открыл файл в 100% — резкость/артефакты в норме.
- [ ] Заголовок читается как предложение, описывает именно ЭТОТ файл.
- [ ] Первые 10 ключей — то, что я сам ввёл бы в поиск для покупки этого файла.
- [ ] Релизы приложены/указаны, ИИ-чекбоксы выставлены.
- [ ] Отправляю.
