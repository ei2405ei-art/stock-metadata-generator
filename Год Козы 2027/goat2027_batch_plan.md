## Workflow батча (повторять 6 раз)

1. **Подготовка файлов** по темам из `goat2027_matrix.csv`. Имя = колонка `Filename` (≤30 симв., латиница, байт-в-байт).
2. **Техконтроль** по `Генератор для ключевания/Adobe_Stock_чек-лист_перед_загрузкой.md`:
   - Photo: 4–100 МП, JPEG sRGB ≤45 МБ, просмотр в 100%, нет выбитых светов/мыла/пыли, горизонт, «воздух» под текст.
   - Video: MP4/MOV, H.264/ProRes, 5–60 с (вертикали 10–30 с), кадр из списка (23.98–60), **нативное** разрешение, без апскейла, штатив, без текста/логотипов/переходов, движение обязательно.
   - Vector: масштабируемый EPS/AI + JPG-превью, без растровых артефактов, чистые контуры.
   - 3–5 лучших на сюжет — остальное в архив («similar content» = главная причина отказов).
3. **Ключевание** — `batch-keyworder.html` (≤30 файлов за прогон):
   - title ≤70 без запятых; keywords 40–49 (цель 45).
   - Сверка с колонками `Title EN` / `Seed keywords EN`: **первые 3 фразы — из матрицы**, дубли между файлами батча недопустимы.
   - AI-файлы: без имён художников/персонажей/брендов в промптах, title и ключах.
4. **AI-чекбоксы** в портале: «Created using generative AI tools» (весь ИИ-контент); «People and Property are fictional» — для p09; тип контента честно: фотореализм → Photos, арт → Illustrations, масштаб → Vectors, движение → Videos.
5. **CSV портала** — `goat2027_adobe_upload.csv` (или перегенерировать из matrix):
   - Только `.csv`, UTF-8, ≤5000 строк, ≤1 МБ, имя без пробелов (`Goat2027_batch1_2026-10-12.csv`).
   - Заголовок точно: `Filename,Title,Keywords,Category,Releases`.
   - Keywords в кавычках, порядок через запятую = порядок важности. Category — номер (8, 15, 12, 7, 1, 9, 18).
   - Releases: подставить реальные имена файлов релизов (JPEG), совпадающие с теми, что загружены.
6. **Загрузка:** файлы + CSV **в одной сессии**. Проверить Sensei-автоключи, категорию, **переставить первые 10** ключей вручную.
7. **После публикации:** первые 30 дней метаданные не трогать. Статистика отказов — в общую таблицу (причина → вывод).

## Риски и как закрыть

| Риск | Решение |
|---|---|
| Лимиты загрузок (с 2025) | Строго 6 батчей по плану, не лить сверх; при отказе — буфер 14–20 дек |
| «Similar content» | В матрице 50 разных смыслов; вариации цвета внутри сюжета не заливать |
| Забыли reorder первых 10 | Шаг 6 workflow обязателен; якорные фразы видны в matrix |
| Русские ключи в EN-аккаунт | RU-колонка matrix — справочная; в upload CSV только EN |
| ИИ отклонён (анатомия/текст) | Проверка п.4 чек-листа; особенно p09 (люди) и видео с кистью/руками |
| Релизы не готовы к батчу 3 | Снять п01/п02/п08 позже или заменить на безлюдные сюжеты из матрицы |
| Модерация тянет >2 недель | Батчи 5–6 не сдвигать: декабрьский пик важнее идеального порядка |
