# Stock Metadata Generator

Одностраничное приложение для генерации метаданных фотостоков (**Adobe Stock / Shutterstock**):
загружаете изображения и видео — получаете продающие **title** и **keywords** на английском
и русском, с учётом требований площадок и коммерческого применения.

Работает полностью в браузере: мультимодальная модель через
[OpenRouter](https://openrouter.ai) анализирует кадр и возвращает готовое описание.

> Никакого бэкенда, сборки и установки. Один HTML-файл — просто откройте его.

---

## Возможности

| | |
|---|---|
| **Анализ изображений и видео** | Для видео автоматически берутся до 3 кадров из разных моментов ролика |
| **Title EN + RU** | Ровно 2 предложения: первое — что в кадре (с учётом реальных поисковых запросов Adobe Stock), второе — смысл и конкретное применение |
| **Keywords EN + RU** | 40–49 штук, первые 3 — уникальные фразы по 2 слова, остальные одиночные |
| **Коммерческие акценты** | Для каждой работы определяются своя аудитория и свой сценарий применения + 3–5 ключей-применений |
| **Анти-дубли по серии** | Ключи и заголовки не повторяются между работами в одной серии |
| **Пакетная обработка** | До 20 файлов за батч с автоматическими повторными проходами при сбоях |
| **Экспорт** | CSV (все работы), JSON, TXT (отдельно по файлу) |
| **Контроль качества данных** | Колонка `source`: `ai` — реальная атрибуция, `heuristic` — аварийная заглушка |

## Требования платформ

| Параметр | Значение |
|---|---|
| Title | 2 предложения, до 180 символов (EN 140–180, RU 120–180) |
| Keywords | 40–49 |
| `no people` | только если людей в кадре нет |
| AI disclosure | `Created using generative AI` |
| Видео | MP4 / H.264, 5–60 секунд, от 1920×1080 |

## Как запустить

**Вариант 1 — просто открыть файл**

Двойной клик по `metadata-generator.html` или адресная строка браузера:

```
file:///C:/путь/к/проекту/metadata-generator.html
```

**Вариант 2 — локальный сервер** (нужно, если браузер ограничивает работу с локальными файлами)

```bash
npx serve .
# или
python -m http.server 8000
```

Затем откройте `http://localhost:8000/metadata-generator.html`.

## Настройка

Приложение работает с двумя провайдерами — выбирается в поле **Провайдер**.

### Вариант A. Ollama — локально, бесплатно и без лимитов

Ни ключей, ни интернета, ни ограничений по количеству запросов. Всё считается на вашем компьютере.

**1. Установите Ollama** — https://ollama.com/download (Windows-версия ставится как обычная программа)

**2. Скачайте vision-модель:**
```bash
ollama pull qwen2.5vl:3b
```

Подходящие модели для 8 ГБ ОЗУ:

| Модель | Размер | Комментарий |
|---|---|---|
| `qwen2.5vl:3b` | ~3 ГБ | Рекомендуется для 8 ГБ ОЗУ |
| `qwen2.5vl:7b` | ~6 ГБ | Качественнее, но заметно медленнее и впритык по памяти |
| `moondream` | ~1.8 ГБ | Быстрая, но описания беднее |

**3. Разрешите запросы из браузера** (без этого браузер блокирует обращение к localhost):
```powershell
setx OLLAMA_ORIGINS *
```
Перезапустите терминал и саму Ollama после этого.

**4. В приложении** выберите провайдера **Ollama**, оставьте адрес `http://localhost:11434`
и модель `qwen2.5vl:3b`.

⚠️ Скорость: на процессоре без видеокарты генерация одного файла занимает **2–4 минуты**
(модель думает над картинкой и пишет ~700 токенов JSON). Батч из 20 файлов — около часа.
Зато бесплатно и без ограничений. С GPU будет в разы быстрее.

### Вариант B. Qwen через Alibaba Model Studio — облако, быстро, бесплатная квота

У моделей Qwen есть полноценное зрение, то есть они **видят изображение** — в отличие от
DeepSeek, который работает только с текстом. Новичкам в Alibaba Cloud выдаётся бесплатная
квота токенов, а генерация в десятки раз быстрее локальной.

1. Зарегистрируйтесь в консоли **Alibaba Cloud Model Studio** и откройте раздел API-KEYS.
2. Создайте ключ (начинается с `sk-`).
3. В приложении выберите провайдера **Qwen**, вставьте ключ, проверьте имя модели и адрес API.

Адрес зависит от региона, в котором вы регистрировались:

| Регион | Адрес |
|---|---|
| Международный | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1/chat/completions` |
| Китай | `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions` |

Модели (смотрите актуальный список в консоли — он регулярно обновляется):

| Модель | Примечание |
|---|---|
| `qwen3-vl-plus` | Vision, рекомендуется по умолчанию |
| `qwen3-vl-flash` | Vision, быстрее и дешевле |
| `qwen-vl-max` | Vision, качественнее |
| `qwen2.5-vl-72b-instruct` | Vision |

Если модель отклонена с ошибкой — сверьте её имя в консоли: приложение выводит точное
название в сообщении об ошибке.

### Вариант C. OpenRouter — облако, если доступен

1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai) и создайте ключ в разделе **Keys**.
2. Вставьте его в поле **API-ключ OpenRouter**.

Ключ хранится только в `localStorage` вашего браузера и уходит напрямум в OpenRouter —
на сторонний сервер он не передаётся. Репозиторий не содержит никаких ключей.

Модели:

| Модель | Примечание |
|---|---|
| `openrouter/free` | Рекомендуется: авто-выбор vision-модели с хорошим качеством |
| `google/gemma-4-26b-a4b-it:free`, `google/gemma-4-31b-it:free` | Vision, бесплатные |
| `nvidia/nemotron-nano-12b-v2-vl:free` | Vision, бесплатные |
| `qwen/qwen3-vl-30b-a3b-instruct`, `qwen/qwen3-vl-8b-instruct` | Платные, качество выше |
| `google/gemini-2.5-flash`, `openai/gpt-4o-mini` | Платные |

Список бесплатных моделей обновляется каждую неделю — их набор меняется. У бесплатного
уровня есть лимит запросов, а у части аккаунтов доступ к OpenRouter ограничивается.

#### Автоматический откат (fallback)

Если OpenRouter ответил `401/402/403` (ключ отклонён, кредиты/квота) или модель стала недоступна
(`MODEL_UNAVAILABLE`), приложение автоматически перебирает запасные варианты в таком порядке:

1. `openrouter/free` — пробует другую бесплатную vision-модель
2. **Qwen** (Alibaba Model Studio) — если вы ввели его API-ключ
3. **Ollama** (локальный) — если он запущен

Как только какой-то провайдер успешно вернул результат — генерация идёт на нём.
Переключение в батче общее на весь прогон (не по каждому файлу).

### Почему не DeepSeek

DeepSeek API принимает только текст: публичных vision-моделей у него нет. Он умеет
причёмывать уже готовый черновик, но **описать изображение не способен**, поэтому
заменить им модель, смотрящую на кадр, нельзя.

## Рабочий процесс

1. Перетащите файлы в зону загрузки (можно сразу много).
2. При необходимости задайте чекбокс **no people** и категорию.
3. Нажмите **«Сгенерировать (батч)»**.
4. Следите за статусом — прогресс идёт по каждому файлу.
5. Выгрузите **CSV** (все работы) или **TXT** по конкретному файлу.

Батч работает последовательно с задержкой, чтобы не упереться в rate limit бесплатных
моделей, и автоматически делает до 3 повторных проходов по файлам, которые не ответили.

## Что означает колонка `source`

| Значение | Что это |
|---|---|
| `ai` | Описание сгенерировано моделью по содержимому кадра |
| `heuristic` | Аварийная заглушка, собранная из имени файла; причина — в поле `ai_error` |

Экспорт CSV по умолчанию выгружает **только записи с `source=ai`**, чтобы в файл
не попали заглушки. Если ИИ-описаний нет вообще — приложение предупредит и предложит
выгрузить 0 записей (безопасный вариант). Если часть записей без ИИ — спросит,
выгружать только AI или все.

## Решение проблем

| Симптом | Причина и решение |
|---|---|
| В описании текст из имени файла | ИИ не ответил, сработала заглушка. Смотрите `source` и `ai_error` в экспорте |
| `HTTP 402 ... can only afford` | На балансе OpenRouter нет кредитов для платной модели. Приложение переключится на `openrouter/free`; либо пополните баланс |
| `MODEL_UNAVAILABLE` | Выбранная `:free`-модель исчезла из каталога. Переключитесь на `openrouter/free` — приложение сделает это само |
| Бесплатно не работает | У бесплатного уровня есть лимит запросов, у части аккаунтов OpenRouter он ограничен. Надёжный выход — провайдер **Ollama** (локально, без лимитов) |
| `Ollama: не удалось обратиться к http://localhost:11434` | Ollama не запущена, либо браузер блокирует запрос: выполните `setx OLLAMA_ORIGINS *` и перезапустите терминал с Ollama |
| `ollama pull qwen2.5vl:3b` (модель не скачана) | Скачайте модель командой из сообщения ошибки; список установленных — `ollama list` |
| Локально очень долго | Это нормально для CPU без видеокарты: 2–4 минуты на файл. Уменьшите размер модели (`moondream`) или включите видеокарту |
| `429 Too Many Requests` | Слишком частые запросы. Приложение повторяет автоматически; при большом батче уменьшите нагрузку |
| «Не удалось получить кадр из видео» | Кодек H.265/HEVC или AV1, либо очень высокий битрейт. Пережмите видео в MP4/H.264 |
| Заголовок не обрезался до 180 | Устаревшая версия страницы в кэше браузера — нажмите **Ctrl+F5** |
| Заголовки и ключи повторяются в серии | Очистите ключи текущего файла и запустите батч заново: приложение подставит ключи предыдущих работ |
